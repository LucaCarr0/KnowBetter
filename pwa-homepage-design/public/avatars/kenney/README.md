# Kenney animal avatars

Source: [Animal Pack Remastered](https://kenney.nl/assets/animal-pack-remastered), by Kenney Vleugels (Kenney.nl).

The 30 PNG files in this directory are unmodified copies of the archive's `PNG/Round/` variant. The other seven variants and vector sheets are not bundled with the app. These files are served locally; displaying an avatar does not contact Kenney or another avatar service.
